# Bela u troje

Blok za upisivanje bodova u beli za tri igrača. Jedna HTML datoteka bez ovisnosti: otvori `index.html` u pregledniku (mobitel, tablet ili računalo).

- Upisuješ tko je zvao adut, bodove iz štihova (treći se izračuna sam do 162) i zvanja.
- Aplikacija računa prolazi li zvač (mora imati više od druga dva igrača zajedno) i upisuje bodove.
- Štiglja (+90), ispravak i brisanje ruku, praćenje tko dijeli, igra do 501, 701 ili 1001.
- Partija se sprema u pregledniku (localStorage).
- Sažetak pravila nalazi se na dnu stranice.
